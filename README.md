# Zed Pico-8 Extension

Zed extension that adds Pico-8 language support (a complete P8 file).

Zed support is based on https://github.com/zed-extensions/lua, using the Tree-sitter grammar from https://github.com/mgmalheiros/tree-sitter-pico8

## Features

- Syntax highlighting
- Bracket rules
- Indentation
- Outline
- Comment highlight for the https://github.com/thedadams/zed-comment extension
